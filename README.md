# WareTrack

WareTrack ir noliktavas pārvaldības sistēma preču uzskaitei un pārvaldībai.

## Funkcijas

- Preču pievienošana, labošana un dzēšana
- Preču meklēšana un filtrēšana
- Kategoriju pārvaldība
- Piegādātāju pārvaldība
- Preču pārvietošana
- Atskaišu apskate
- Lietotāju pārvaldība

## Izmantotās tehnoloģijas

- Next.js
- React
- TypeScript
- Tailwind CSS
- Python
- FastAPI
- SQLite
